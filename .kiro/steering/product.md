# Product Overview

MySQLデータベースを運用する開発者・運用担当者向けのツールです。指定したレコードと、それを直接・間接に参照する子孫レコードを、漏れなく正しい順序で安全に削除できるようにします。構成は2つで、スキーマ構造をファイルに書き出す**ダンプスクリプト**と、そのファイルを入力に削除計画を立てて実行する**Go製CLI**です。

## Core Capabilities

- **スキーマのダンプ**: テーブル、カラム、主キー、外部キー（複合キーを含む）を、機械可読なスキーマファイルに書き出す
- **関連の補完**: 外部キー制約のない関連を、手動リレーション定義で補う
- **子孫レコードの特定**: 起点レコードを参照するレコードを再帰的に集める（自己参照・循環参照に対応）
- **安全な削除**: 既定は dry-run。明示的な実行指定と確認があって初めて、単一トランザクションで全件まとめて削除する

## Target Use Cases

- テストデータや退会ユーザーなど、特定エンティティに紐づくデータを一括で消す
- 外部キー制約が不完全なレガシースキーマで、関連データを削除漏れなく扱う
- 削除前に「何がいくつ消えるか」をレビューしてから実行する

## Value Proposition

- **安全側がデフォルト**: プレビューが既定。実行は明示フラグと確認が必須。件数上限ガードがあり、失敗したら全件ロールバックする
- **予測可能な挙動**: ON DELETE ルールに左右されず、参照している子は常に削除対象にする
- **レビュー可能**: スキーマファイルとリレーション定義はテキストなので、バージョン管理やレビューができる

## Product Principles

- 削除系の判断で迷ったら、安全側（何もしない・中止する）に倒す
- 認証情報をコマンドライン引数・画面出力・ログに出さない
- スコープは MySQL のレコード削除に限定する。バックアップ、条件式での指定、他DB対応は対象外
